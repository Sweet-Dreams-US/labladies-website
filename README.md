# Lab Ladies, LLC — Website

Nurse-owned concierge mobile laboratory services for Palm Beach and Broward County, Florida.

- **Live:** https://labladies-website.vercel.app
- **Domain:** labladies.com (13 alias domains redirect to it — see HANDOFF.md)
- **Contact:** 954-605-3725 · labladies2026@gmail.com

## Stack
Next 16 · React 19 · Tailwind 4 · TypeScript · App Router (`src/`). No CMS — copy lives in
`src/lib/site.ts` and the page files.

```bash
npm install
npm run dev
```

See `AGENTS.md` for the content rules that govern this site (brand palette, accessibility
floor, PCR positioning, and the client's standing "no IV therapy" instruction).
